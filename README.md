# Проверка текстов

Плагин для проверки языка, логики и фактов в текстах, PDF, PPTX, XLSX, DOCX, JPEG/PNG и доступных макетах Figma. Все пояснения и отчёты — на русском языке. Версия 0.1.0.

## Как пользоваться

Вызовите «Проверка текстов», приложите материалы и напишите, например:

> Проверь все тексты в этих файлах. Покажи место ошибки, исходный текст, исправление и пояснение. Подготовь полный отчёт в XLSX.

Можно указать отдельные страницы, слайды, листы или фреймы, приложить словарь названий и первичные источники для сверки.

До 20 замечаний плагин выводит полный отчёт в чате. При большем количестве либо по запросу формирует XLSX с листами «Сводка», «Ошибки», «Уточнения», «Предложения», «Покрытие», «Факты». В списках замечаний есть фильтры и отметка «Исправлено».

## Что проверяется

| Группа | Содержание |
|---|---|
| Грамматические ошибки | Орфография, пунктуация, согласование, управление, построение предложений |
| Речевые ошибки | Значение и сочетаемость слов, неоправданные повторы, избыточность |
| Логические и фактические ошибки | Противоречия, причинные связи, даты, имена, события, числа и расчёты |

Подтверждённые ошибки отделяются от уточнений, непроверенных фактов и редакторских предложений. Для каждого замечания сохраняются точная цитата и адрес. Для фактического исправления нужен источник, для числового — расчёт. Если правильная дата или число неизвестны, плагин задаёт вопрос.

## Возможности среды

Пакет использует GPT для анализа и доступные инструменты среды для чтения, визуального просмотра, вычислений, Figma и поиска. Собственного сервера, ключа API и платного сервиса OCR пакет не требует. Зависимости Python нужны только при запуске локальных вспомогательных скриптов.

| Материал | Локальное извлечение | Дополнительная проверка |
|---|---|---|
| PDF | Текстовый слой, адреса и координаты | Сканы, изображения, порядок чтения |
| DOCX | Текст, таблицы и доступные служебные области | Визуальное представление и неподдерживаемые объекты |
| PPTX | Текст, группы, таблицы, заметки | Изображения, диаграммы, сложные объекты |
| XLSX | Все хранимые непустые ячейки, формулы и кэш | Актуальность расчётов, отображение, графические объекты |
| JPEG, PNG | OCR при наличии Tesseract с русским языком | Визуальная сверка; без OCR — чтение изображения инструментами среды |
| Figma | Через подключённые инструменты среды | Доступ к файлу, текстовые слои и изображения фреймов |

Экстрактор всегда обозначает результат как частичное извлечение. Он не выполняет корректуру и не гарантирует полноту видимого текста. Ограничения проходят в отчёт до фактической дополнительной проверки. Excel не пересчитывается. Публичные факты требуют доступного веб-поиска или приложенных источников.

## Локальная проверка пакета

Требуется Python 3.10 или новее. Команды выполняются из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/validate_package.py
python -m unittest discover -s tests -p 'test_*.py' -v
```

Пример сборки демонстрационного отчёта:

```bash
python skills/proverka-tekstov/scripts/build_report.py skills/proverka-tekstov/assets/report-example.json --output work/Пример_отчёта.xlsx
```

Для извлечения текста передайте путь к собственному материалу:

```bash
python skills/proverka-tekstov/scripts/extract_text.py материал.pdf --output work/Извлечение.json
```

Эти скрипты не отправляют документы в сеть. Интернет-проверка и работа с Figma выполняются отдельно инструментами среды. Проверяемые документы и созданные отчёты не нужно добавлять в репозиторий.

## Подключение

Пакет готовится для установки из репозитория в поддерживаемой среде ChatGPT/Codex. Если используется CLI с поддержкой плагинов, для локального каталога доступна команда:

```bash
codex plugin marketplace add .
```

После подключения источника выберите «Проверка текстов» в каталоге плагинов и установите его. Доступ к Figma подключается отдельно. Подробнее — [Публикация](docs/Публикация.md).

Структура пакета сверена с [официальной документацией OpenAI](https://developers.openai.com/plugins/build/plugins). Публикация в GitHub и публикация в общем каталоге плагинов — отдельные действия.

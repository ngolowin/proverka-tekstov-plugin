# Отчёт о проверке

## Ответ в чате

Указать перечень материалов и область. Дать числа подтверждённых ошибок по трём группам, вопросов и непроверенных фактов. Сразу обозначить частичность проверки, если она есть.

Пример структуры (цифры и цитаты заменять фактическими данными):

> Проверено 12 слайдов: 11 полностью, 1 частично. Найдено 3 подтверждённые ошибки. Один факт не проверен. На слайде 8 не удалось прочитать мелкий текст изображения.

| № | Где | Исходный текст | Исправление или вопрос | Тип | Пояснение |
|---|---|---|---|---|---|
| 1 | Слайд 2, заголовок | Современное исскуство | Современное искусство | Орфография | Неверно написано слово «искусство» |

Разделять подтверждённые ошибки, уточнения/непроверенные факты, редакторские предложения и ограничения покрытия. Для фактических исправлений приводить URL источника, для числовых — выражение расчёта.

Если подтверждённых ошибок нет: «В проверенной части материала подтверждённых ошибок не найдено». Затем указать ограничения и непроверенные факты, если есть. Не делать общего вывода о готовности к публикации при непроверенных областях.

До 20 замечаний включительно показывать полный список в чате. Более 20 — сводку и полный XLSX. По явной просьбе создавать XLSX при любом объёме. Если инструмента создания файла нет, дать полный список текстом, при необходимости частями.

## Данные для XLSX

Записать JSON в UTF-8. Все перечисленные ключи обязательны, неизвестные поля не добавлять. Значения полей — строки; коллекции — массивы объектов. Для примера открыть `../assets/report-example.json`.

| Верхний ключ | Содержание |
|---|---|
| название | Название отчёта |
| источники | Объекты с полями `название`, `область` |
| замечания | Объекты с полями из следующей таблицы |
| покрытие | Объекты с полями `файл`, `область`, `статус`, `причина` |
| факты | Объекты с полями `утверждение`, `место`, `статус`, `источник`, `дата_проверки` |

| Поле замечания | Правило |
|---|---|
| id | Уникальная строка, например `001` |
| файл | Имя материала; для текста в чате — `Сообщение пользователя` |
| место | Страница, слайд, ячейка, фрейм или область; все адреса объединённого замечания |
| исходный_текст | Точная цитата, включая ошибку; для противоречия — обе цитаты с адресами |
| группа | `Грамматические ошибки`, `Речевые ошибки` или `Логические и фактические ошибки` |
| тип | Например `Орфография`, `Пунктуация`, `Грамматика`, `Лексика`, `Тавтология`, `Плеоназм`, `Логика`, `Факт`, `Расчёт` |
| статус | `Ошибка подтверждена`, `Нужно уточнение`, `Факт не проверен` или `Редакторское предложение` |
| исправление | Готовая минимальная правка или конкретный вопрос; пустая строка, если правки нет |
| пояснение | Краткое основание замечания |
| источник | URL/название источника, расчёт или пустая строка для очевидной языковой ошибки |
| приоритет | `Высокий` при влиянии на смысл, сумму, срок или адресата; иначе `Обычный` |

Статусы покрытия: `Проверено полностью`, `Проверено частично`, `Не проверено`. Для неполного покрытия обязательно содержательно объяснить причину. Статусы фактов: `Подтверждено`, `Опровергнуто`, `Факт не проверен`, `Нужно уточнение`. Дата проверки — фактическая дата в виде `ГГГГ-ММ-ДД`, либо пустая строка, если проверки не было. У неподтверждённого факта не придумывать источник.

Не включать записи без реальной цитаты в лист ошибок. Ограничение распознавания записывать в покрытие. Если часть фактов не проверена, отразить это в реестре и сводке, даже когда все страницы были прочитаны.

Дубликаты одного физического места удалять до формирования JSON. При объединении нескольких мест одной ошибки перечислить все адреса в поле `место`; сводка считает записи замечаний, а не количество отдельных вхождений. Не называть это числом всех вхождений.

Не использовать фрагменты исходника как формулы Excel. Генератор сохраняет строки как текст и отклоняет данные, которые нельзя поместить в ячейку без потерь. При такой ошибке разделить запись на явно связанные строки с уникальными `id`, сохранив смысл и все цитаты, либо выдать полный текстовый отчёт. Не обрезать текст молча.

## Листы XLSX

| Лист | Содержание |
|---|---|
| Сводка | Источники, количества записей по статусам и группам, покрытие |
| Ошибки | Только подтверждённые ошибки |
| Уточнения | Вопросы и факты без достаточного подтверждения |
| Предложения | Необязательные редакторские изменения |
| Покрытие | Проверенные и непроверенные области с причинами |
| Факты | Утверждения, результаты, источники и даты сверки |

Столбец «Исправлено» — отметка пользователя `Да/Нет`; исходное значение `Нет`. Он не заменяет статус подтверждения замечания и не означает повторную проверку файла. При повторной проверке читать новую версию материала.

# Размещение и подключение

## GitHub

Пакет размещается целиком, с каталогами `.agents` и `.codex-plugin`. Веб-интерфейс загрузки файлов может не показать скрытые каталоги, поэтому предпочтительно отправлять подготовленный Git-репозиторий.

После выбора целевого репозитория добавьте его фактический URL как `origin` и отправьте ветку `main`. Не отправляйте материалы, которые проверял пользователь, файлы отчётов, ключи или настройки доступа.

Для нового личного репозитория можно использовать GitHub CLI после входа в свой аккаунт. Команда ниже создаёт закрытый репозиторий с подготовленным именем; выполнять её только если такого репозитория ещё нет:

```bash
gh repo create proverka-tekstov-plugin --private --source . --remote origin --push
```

Для существующего репозитория сначала проверьте его содержимое и выберите отдельную ветку, чтобы не заменять существующий проект. Публикация не требует изменения видимости репозитория на открытую.

## Подключение каталога

В поддерживаемом CLI подключите фактический адрес репозитория командой `codex plugin marketplace add`, затем установите «Проверка текстов» из добавленного источника в каталоге плагинов. Способ импорта в рабочую область зависит от доступных функций и прав аккаунта. Один push в GitHub не устанавливает плагин автоматически.

## Что проверить после установки

1. Плагин находится по русскому названию и отвечает на русском.
2. Запрос «Проверь текст» запускает вычитку.
3. Скрипты читают файлы в текущей среде либо явно сообщают недоступные возможности.
4. XLSX создаётся с шестью листами и сохраняет исходные цитаты.
5. Ссылка Figma проверяется при наличии подключения и доступа. Без доступа предлагается экспорт.
6. Внешний факт подтверждается источником; без поиска получает статус «Факт не проверен».
7. Неразборчивые и неподдерживаемые области видны в покрытии.

Для обновления измените версию в обоих манифестах, выполните тесты, отправьте изменения и обновите источник плагина. Не подменяйте опубликованную версию другим содержимым без изменения номера.

## Общий каталог плагинов

Размещение кода на GitHub само по себе не публикует плагин в общем каталоге ChatGPT/Codex. Для этого предусмотрены отдельная подача и проверка. Текущий пакет ориентирован на личное и командное использование из репозитория.

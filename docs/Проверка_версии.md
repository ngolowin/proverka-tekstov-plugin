# Проверка версии 0.1.0

Дата: 23 сентября 2026 года.

## Выполнено

- Локальная проверка манифестов, каталога, инструкции, связанных ресурсов и синтаксиса Python — успешно.
- Валидатор навыка — успешно.
- Автоматические тесты — **18 из 18 успешно**: 9 для извлечения, 9 для отчёта.
- Независимая проверка скриптов: два дефекта исправлены и покрыты регрессионными тестами — неразрывный дефис DOCX и прозрачность PNG перед OCR.
- Пробное применение инструкции в отдельном диалоге к тексту восьми слайдов: найдены все шесть заложенных ошибок; повтор в слогане не объявлен ошибкой; избыточность выделена как необязательная правка; внешняя дата без источника оставлена непроверенной.

## Что подтверждают автоматические тесты

DOCX: таблицы, вложенные таблицы, гиперссылки, колонтитулы, изображения и неразрывный дефис. PPTX: группы, таблицы, заметки, скрытый слайд, изображения. XLSX: дальняя ячейка C10500, скрытые области, формула и сохранённый результат. PDF: текст, координаты, страница-скан. Изображения: честное поведение без русского OCR и подготовка прозрачного PNG.

Отчёт: маршрутизация записей по листам, точность цитат, текстовые значения вместо выполнения формул, отказ при некорректной схеме/статусах/дубликатах, отсутствие молчаливого обрезания текста, причины частичного покрытия, основания фактов, пустой отчёт и командный запуск.

## Границы проверки

- Реальное русское распознавание Tesseract не проверялось: языковая модель `rus` отсутствует. Интерфейс OCR и координаты проверены имитацией ответа Tesseract.
- Реальный файл Figma и авторизация не использовались. Этот путь зависит от подключённых инструментов и доступа пользователя.
- Установка именно этого пакета через GitHub в интерфейсе ChatGPT/Codex пока не проверена. Структура сверена с опубликованной документацией, но локальный валидатор не является сертификацией платформы.
- Внешняя проверка фактов в пробном сценарии была запрещена специально, чтобы проверить корректный статус непроверенного факта. Качество поиска источников этим сценарием не измерялось.
- Тесты не доказывают полноту извлечения всех возможных объектов Office/PDF или безошибочность языковой модели. Обязательная визуальная сверка и учёт покрытия остаются частью инструкции.

## Среда тестов

Проверенные библиотеки: python-docx 1.2.0; python-pptx 1.0.2; openpyxl 3.1.5; PyMuPDF 1.26.6; Pillow 12.3.0. Тесты создают временные синтетические файлы; пользовательские документы в репозитории отсутствуют.

Повторный запуск из корня:

```bash
python scripts/validate_package.py
python -m unittest discover -s tests -p 'test_*.py' -v
```
